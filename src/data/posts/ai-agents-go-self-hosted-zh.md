这周的智能体新闻有个模式，单独看每一条容易错过。Gemini 4 Hydrogen。自托管 Claude 智能体。Replit 智能体商务。Grok Bot 1.0。AlphaGenome 2。每一款来自不同的实验室，都是不同的产品。合起来看，它们描述的是同一个转变：智能体正在从云端搬到用户自己控制的硬件上，问题不再是智能体能不能用，而是由谁来运行它。

## 从演示到基础设施

一年前，AI 智能体是个演示。你看一段视频，模型订了机票、写了个函数，演示本身就是产品。智能体住在实验室的服务器上，你按 token 付费，关掉标签页或者账单太高，它就停了。

现在走红的恰恰是反过来的形态。自托管 Claude 智能体意味着智能体跑在你的机器或服务器上，对着你的代码库，你的数据不出自己的网络。Replit 的智能体商务意味着智能体开始交易——替你干活赚钱，而不只是产出文字。本地编程助手意味着最常见的智能体任务（写代码、改代码）发生在代码本来就在的地方。智能体不再是你去访问的云服务，而变成了你拥有的基础设施。

这比任何一次单点能力跃升都更能改变经济学。云端智能体每走一步都计费，意味着每个动作头顶都挂着一块表。自托管智能体花的是算力，算力便宜而且越来越便宜，多做一个动作的边际成本趋向于零。动作便宜了，智能体就不再是你试一次的新鲜玩意，而变成你围绕它搭建工作流的习惯。榜单量到的正是这个转变：GitHub 上走红的不再是智能体演示，而是智能体运行时、框架和工具——为"智能体持续运行而不是按需启动"的世界准备的管道。

## 为什么是自托管，为什么是现在

三件事同时发生了。第一，开源模型够好了。一个需要规划、用工具、从错误中恢复、持续工作一小时的智能体，不能跑在弱模型上——它会跑偏或者死循环。以中国实验室为首的这一代开源模型，已经能支撑长时间的智能体任务而不需要持续监督。这是一个门槛，跨过去，自托管智能体就从"向往"变成了"可行"。

第二，运行这些模型的成本降下来了。量化、更好的推理引擎、更便宜的硬件，意味着一个有能力的模型现在可以在一块好显卡甚至一台高端笔记本上跑。智能体不需要数据中心，它需要一台机器，而这台机器越来越多是用户本来就有的。

第三，信任。一个会订票、会购买、会编辑、会部署的智能体，是一个拥有权限的智能体，而权限交给跑在自己机器上的软件，比交给第三方运营的服务更容易。自托管智能体是可以审计的——你能看到它做了什么、读了什么、改了什么，因为日志是你的。对真正用智能体干活的开发者（也就是榜单量到的人群）来说，这种可审计性不是锦上添花，而是让智能体碰任何重要东西的前提。

## 智能体便宜又本地化之后，什么变了

第一个变化是谁来建造。当一个智能体任务的成本从几美元降到几分钱，值得自动化的任务集合就极大地扩张了。昂贵的高价值任务先被自动化，现在轮到长尾：那些小而无聊、频繁出现、没人愿意付 API 价格去自动化、但加起来就是大部分工作的任务。这就是为什么现在走红的智能体框架都是通用型的——它们是为长尾造的，不是为某一个展示任务造的。

第二个变化是造出了什么。云端智能体是你订阅的产品，本地智能体是你嵌入的组件。差别体现在 GitHub 榜单上：走红的智能体项目是库和运行时，不是应用。开发者不是在找一个更好用的智能体，而是在找更好的零件来造自己的智能体。这是一项技术从产品走向平台的标志，也是生态开始复利的节点——每个智能体框架都让下一个更容易造，每个造了智能体的开发者都成为下一个的用户。

第三个变化是竞争逻辑。在云端智能体的世界里，造出最好模型的实验室赢，因为模型就是产品。在自托管的世界里，造出最*好用*模型的实验室赢，因为模型是组件，组件比的是多容易装进开发者已有的东西里。这是另一种游戏，而它偏爱开放：一个随处可跑、能针对特定工作微调的开源模型，会打败一个能力稍强但只能租用的封闭模型。榜单用 trending 仓库的语言说了好几个月，这周智能体新闻用大白话又说了一遍。

智能体浪潮没有结束，它在变形状——从你围观的东西，变成你运行的东西。榜单照例提前捕捉到了这个变化。现在有意思的问题不再是智能体行不行，而是当运行一个智能体几乎不花钱之后，人们会造出什么。
